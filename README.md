# WINX ROLEPLAY

![Cover](.gitbook/assets/7ca435e2-08be-4d9a-8270-93acaf90a567.png)

Aqui, você não entra apenas em uma cidade. Você faz parte de um universo onde cada escolha muda o rumo da sua história.

A **Winx** foi criada para quem busca uma experiência de roleplay intensa, organizada e inovadora. Cada sistema, evento e detalhe foi pensado para entregar um RP de alto nível, valorizando a criatividade e a imersão de todos os jogadores.

Na **Winx**, sua reputação é construída pelas suas ações. Cada conquista tem valor, cada decisão gera consequências e cada jogador ajuda a escrever a história da cidade.

#### 🚀 O próximo protagonista é você.

Entre, viva novas experiências, faça alianças, supere desafios e deixe sua marca.
